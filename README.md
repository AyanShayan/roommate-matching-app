# Roommate Matching Application

## Project Overview
Development of a Compatibility-Based Roommate Matching Application for University Students.

This project aims to develop a mobile application that uses Machine Learning to recommend compatible roommates based on students' lifestyle habits, preferences, and living requirements.

## Problem Statement
University students may experience difficulties finding suitable roommates due to differences in sleep schedules, cleanliness, noise tolerance, and personal habits. The application aims to support more informed roommate selection.

## Target Users
University students who are looking for compatible roommates for shared accommodation.

## Project Objectives
- Develop a mobile application for Android and iOS.
- Implement student registration and profile management.
- Design a lifestyle compatibility questionnaire.
- Develop an ML-based roommate matching algorithm.
- Provide personalized roommate recommendations.
- Evaluate ML performance against a rule-based baseline.
