# Mobile UX Prototype

## Development of a Compatibility-Based Roommate Matching Application for University Students

**Prepared by:** Ayan Matayev

**Supervisor:** Tomiris Zhaksylyk

**YouTrack Task:** RMM-9

**Design Tool:** Figma

**Status:** Prototype for Pre-Defense 1

## 1. Purpose

The purpose of this prototype is to demonstrate the proposed user interface and main interaction flows of our mobile roommate matching application.

The design is based on the project requirements, student interviews, and system architecture.

## 2. Prototype Link

**Figma Prototype:** https://www.figma.com/design/zVzAKw38CXKzEMXBPlZguu/RoommateMatch-%E2%80%94-Mobile-UX-Prototype--RMM-9-?node-id=0-1&t=N0rFL0120HBnz18P-1

## 3. Main Screens

The prototype includes 12 mobile screens covering user registration, profile creation, lifestyle questionnaires, accommodation preferences, roommate recommendations, compatibility explanations, filters, and privacy settings.

## 4. Main User Flow

Welcome → Registration → Profile Setup → Lifestyle Questionnaire → Accommodation Preferences → Roommate Recommendations → Candidate Profile → Compatibility Details.

Additional navigation includes sign-in, filtering, and profile management.

## 5. Design Principles

The proposed interface follows these principles:

- Simple navigation and clear buttons.
- Readable text and consistent visual hierarchy.
- Short, understandable questionnaire questions.
- Easy comparison of roommate preferences.
- Clear explanations of compatibility factors.
- Privacy-conscious profile presentation.

## 7. Prototype Limitations

This prototype demonstrates the planned interaction design and does not connect to a working backend or trained Machine Learning model.

All example student profiles and compatibility values are fictional demonstration data.

User usability testing and implementation will be performed during subsequent development stages.

## 8. Planned Evaluation

The prototype will be evaluated by asking representative student users to complete key tasks:

- Create a student profile.
- Complete the lifestyle questionnaire.
- Find potential roommates.
- Review a compatibility explanation.
- Apply search filters.

Feedback will be used to improve interface clarity and navigation.

## 9. Conclusion

The Figma prototype demonstrates the intended mobile experience for our compatibility-based roommate matching application.

It provides a foundation for React Native implementation and future usability evaluation.
